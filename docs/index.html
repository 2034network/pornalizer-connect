Pornalizer Connect

A WordPress plugin that embeds and syncs video content from Pornalizer — live grid, lightbox player, AJAX search, and automatic background sync.

Download latest release View on GitHub

Live video grid

Drop-in shortcode — no manual embedding required.

Lightbox player

Clean in-page playback, no redirect off your site.

AJAX search

Instant client-side filtering across your synced catalog.

Auto-sync

WP-Cron keeps your catalog current, with an optional drip mode.

Signed embed links

HMAC-SHA256 signed, 2-hour expiry, domain-bound — no hotlinking.

Simple setup

Upload the zip, activate, connect. That's it.

Requires WordPress 5.8+ and PHP 7.4+.
